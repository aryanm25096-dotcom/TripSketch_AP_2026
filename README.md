## DBMS Deliverables (`dbms/`)

All database artifacts and checkpoint submissions are located in the [`dbms/`](dbms/) directory:

| Deliverable | Description |
|-------------|-------------|
| [`dbms/01_normalization.md`](dbms/01_normalization.md) | Full relational normalization analysis taking the application data model through **1NF → 2NF → 3NF (and BCNF)** with functional dependencies, data dictionary, and proofs. |
| [`dbms/02_er_diagram.png`](dbms/02_er_diagram.png) | Entity-Relationship (ER) diagram illustrating entities, primary/foreign keys, and cardinalities. |
| [`dbms/03_schema.sql`](dbms/03_schema.sql) | DDL script defining the 3NF/BCNF relational tables with strict constraints, foreign keys, and indexes for PostgreSQL. |
| [`dbms/04_load_data.sql`](dbms/04_load_data.sql) | Seed data script loading sample states, locations, vibes, crowd levels, spots, tags, itineraries, and users. |
| [`dbms/04_queries.sql`](dbms/04_queries.sql) | Application workload queries with `-- READ` / `-- WRITE` annotations and IDs (`R1`–`R6`, `W1`–`W6`). |
